# Sample Test Application

This is a simple web application for demonstrating AI-QA-Agent capabilities.

## Features

- User registration and login
- Product catalog
- Shopping cart
- Checkout process
- User profile management

## Tech Stack

- Next.js
- TailwindCSS
- SQLite (for demo)

## Running the Sample App

```bash
cd sample-app
npm install
npm run dev
```

The app will be available at http://localhost:3001
